# Architecture

## Purpose

`trysac-prompt-injection-guard` is a small, dependency-free Python library: Screen user input and retrieved content for prompt injection with explainable rules, Unicode obfuscation removal including tag characters, and an optional classifier that can only raise the score

## Shape

```text
caller code --> prompt_injection_guard (public API in __init__.py)
                    |
                    +-- pure functions, no I/O, no global state
```

- **Public API**: the names listed in `__all__` of `src/prompt_injection_guard/__init__.py`. Anything else is
  internal and may change without a major version.
- **Errors**: invalid input raises built-in exceptions (`ValueError`, `TypeError`) with a clear
  message; the library never prints or exits.
- **Side effects**: none. If a feature needs I/O, isolate it in its own module behind a small
  interface and record the choice in an ADR.

## Quality contract

`scripts/check.py` is the single definition of the gates; `fabrica.json` tells the factory and CI
how to run it. See [TESTING.md](TESTING.md).
